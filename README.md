# Aromat Tools

Десктопное приложение для работы с этикетками на Windows 10 и 11.

## Установка через Git

1. Установите [Git для Windows](https://git-scm.com/download/win) и [Node.js LTS](https://nodejs.org/download).
2. Откройте Git Bash. Перейдите в папку, где хотите хранить приложение, и выполните:

   ```bash
   git clone https://github.com/Artemzzhu/aromat_tools.git
   cd aromat_tools
   ./install.cmd
   ```

   Если репозиторий уже скачан, выполните в его папке `git pull --ff-only` и `./install.cmd`. Также можно открыть `install.cmd` из Проводника.
3. Запустите **Aromat Tools** с рабочего стола. Ярлык использует логотип приложения и запускает Electron напрямую.

Репозиторий, приложение и зависимости хранятся в папке `aromat_tools`. Если перенесёте папку, запустите `install.cmd` в новом месте, чтобы обновить путь в ярлыке.

## Обновление

Закройте Aromat Tools и запустите `update.cmd` в папке приложения. Скрипт загружает изменения из Git, обновляет зависимости и обновляет ярлык рабочего стола. Приложение можно запустить тем же ярлыком.

Загруженные этикетки и их названия хранятся в локальном профиле Aromat Tools. После обновления они доступны под той же учётной записью Windows. Количество экземпляров вводится заново после запуска.
