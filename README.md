# Aromat Tools

Десктопное приложение для работы с этикетками на Windows 10 и 11.

## Установка через Git

1. Установите [Git для Windows](https://git-scm.com/download/win) и [Node.js LTS](https://nodejs.org/download).
2. Откройте Git Bash. Перейдите в папку, где хотите хранить приложение, и выполните:

   ```bash
   git clone https://github.com/Artemzzhu/aromat_tools.git
   cd aromat_tools
   ./install.cmd
   ```

   Если репозиторий уже скачан, выполните в его папке `git pull --ff-only` и `./install.cmd`. Также можно открыть `install.cmd` из Проводника.
3. Запустите **Aromat Tools** с рабочего стола. Ярлык использует логотип приложения и запускает Electron напрямую.

Репозиторий, приложение и зависимости хранятся в папке `aromat_tools`. Если перенесёте папку, запустите `install.cmd` в новом месте, чтобы обновить путь в ярлыке.

## Обновление

Закройте Aromat Tools и запустите `update.cmd` в папке приложения. Скрипт загружает изменения из Git, обновляет зависимости и обновляет ярлык рабочего стола. Приложение можно запустить тем же ярлыком.

Загруженные этикетки и их названия хранятся в локальном профиле Aromat Tools. После обновления они доступны под той же учётной записью Windows. Количество экземпляров вводится заново после запуска.

## Поставки Ozon FBO

В Aromat Tools откройте «Поставки Ozon FBO» → «Настройки Ozon». Введите Client ID и API Key с доступом к FBO, проверьте подключение и сохраните настройки. Ключ шифруется системным хранилищем. Отчёты хранятся в локальном профиле, отдельно по Client ID и периоду.

Выберите даты и загрузите поставки. Период включает обе даты и определяется по локальной дате начала таймслота Ozon. Отчёт учитывает заявки и отдельные поставки со статусом `COMPLETED`. «Заявлено к поставке» — это `quantity` из товарного состава поставки. Количество в упаковке `quant` и фактическая приёмка в этот показатель не входят. Группировка идёт по паре «артикул продавца + SKU». Товары без артикула остаются отдельными по SKU.

«Обновить данные» заново загружает период. «Повторить загрузку пропусков» снова проверяет заявки и использует уже загруженные составы, если идентификатор состава не изменился. У неполного отчёта есть предупреждение и список пропусков. Кнопка «Экспорт в Excel» сохраняет сводку, детализацию и пропуски в одном файле.

Контракт проверен по [официальной схеме Seller API](https://docs.ozon.ru/api/seller/swagger.json). Список заявок использует `/v3/supply-order/list`, детали — `/v3/supply-order/get`, товарный состав — `/v1/supply-order/bundle`. При HTTP 400 на запрос с фильтром таймслота приложение повторно загружает завершённые заявки без этого фильтра и проверяет даты локально. Состав запрашивается по одному `bundle_id` на вызов. Метод `/v1/supply-order/act/product/get` описывает акты, включая заявленное и принятое количество. Он не участвует в расчёте сводки по заявкам.

Проверки расчётов и экспорта запускаются командой `npm test`.

## Этикетки DesignPro

В разделе «Печать этикеток» можно загружать PDF и файлы ZDL с макетом типа «ДОЛЬЧЕ ВИТА — БАККАРА». Aromat Tools вписывает такой макет в размер 43 × 25 мм с сохранением пропорций. Даты «Изготовлено» и «Годен до» вводятся в формате ММ.ГГГГ. Чтобы проверить изменения на этикетке, нажмите «Обновить предпросмотр». Сохранённые даты можно изменить кнопкой «Изменить» рядом с этикеткой.
